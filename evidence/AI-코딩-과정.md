# AI 코딩 도구 사용 과정

이 문서는 실제 Codex 대화에서 과제에 해당하는 요청과 작업 내용을 정리한 대화 기록입니다. 자동 검사 기록도 포함합니다.

## 1. 과제와 아이디어

**사용자:** “새과제인데”라고 하며 HTML/CSS/JavaScript, Python Vercel Function, GitHub, Vercel 배포, AI 기능이 필요한 미션 전문을 제공함.

**Codex:** 서비스 아이디어와 실제 AI 연동에 필요한 API 키 보유 여부를 질문함.

**사용자:** “AI 프롬프트 개선기”를 선택하고 “OpenAI API 키가 있어요”라고 답함. 키 값은 대화에 공유하지 않음.

## 2. 설계와 구현

**Codex:** 별도의 서비스로 “프롬프트 공방”을 기획하고, 홈·프롬프트 다듬기·이용 방법의 세 섹션을 작성함. 프론트엔드는 순수 HTML/CSS/JavaScript로 만들고, `api/improve.py`에 Python 함수를 구현함. 브라우저는 `fetch('/api/improve')`로 요청하며 API 키는 서버 환경 변수에서만 읽도록 작성함.

**Codex:** 입력 누락, 길이 초과, API 오류, 응답 지연의 안내 문구를 넣고, 반응형 CSS와 결과 복사 버튼을 구현함.

## 3. 오류 확인과 수정

**Codex:** 선택 항목에 문자열 이외의 값이 들어올 때 서버 오류가 나지 않도록 입력 검사를 보강함. JavaScript에서 폼 항목 접근을 명시적인 요소 참조로 변경하고, 서버가 JSON이 아닌 응답을 보낼 때에도 사용자에게 오류 메시지를 보여주도록 수정함.

**자동 검사:** Python API 입력·출력 검사 5개가 통과했고, JavaScript 구문 검사도 통과함. 실제 OpenAI 호출과 배포 화면 검증은 Vercel 환경 변수 등록 후 수행할 예정임.

## 4. 제출용 추가 증빙

가능하면 이 대화 화면에서 과제 요구사항과 구현 결과가 보이는 스크린샷도 저장합니다. API 키 화면이나 값은 캡처하지 않습니다.
